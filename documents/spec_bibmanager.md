# 文献管理ツール 要件定義書・仕様書

**プロジェクト名:** BibManager（仮称）  
**作成日:** 2026-04-01  
**対象ユーザー:** 物性理論・数理物理学の研究者（個人利用）

---

## 1. プロジェクト概要

### 1.1 背景と目的

現在、数百件規模の文献情報を単一の `.bib` ファイルで管理しているが、以下の問題がある。

- bibファイル単体では検索性・閲覧性が低い
- Notionで補完管理しているが、bibとの同期が手動かつ煩雑で、動作も重い
- タグ・キーワード・メモなどの付加情報をbibと一元管理できていない

本ツールは、**bibファイルを正として双方向に同期しながら**、タグ・メモ・検索等のリッチな文献管理機能をローカルで高速に提供するWebアプリケーションを構築する。

### 1.2 現行Notionとの対応関係

| Notionの列 | 新ツールでの扱い |
|---|---|
| タグ | タグ（多対多、階層なし） |
| キーワード | キーワード（複数、フリーワード） |
| arXiv掲載年月 | bibフィールド `eprint` + `year`/`month` から自動抽出 |
| 著者 | bibフィールド `author` から自動抽出 |
| タイトル | bibフィールド `title` から自動抽出 |
| 何が書かれていると他の文献で言っていたか | 「他文献での言及」メモ（ソース文献付き複数記録対応） |
| 読んでみて実際に何が書かれていたか | 「自分の読書メモ」（自由記述） |
| bibtex情報 | bibエントリ（表示・編集・エクスポート） |

## 2. システム構成

### 2.1 アーキテクチャ方針

**推奨スタック:** Python (Flask) + SQLite + HTML/CSS/JS (バニラ or 軽量フレームワーク)

- **バックエンド:** Python (Flask)
  - macOS環境でのローカル実行に最適
  - Python経験者が保守しやすい
  - Claudeが都度改修するのに明快な構造
- **データベース:** SQLite
  - インストール不要、単一ファイル管理
  - bibデータ＋付加情報を一元管理
  - 高速な全文検索が可能
- **フロントエンド:** HTML/CSS/JavaScript（シングルページ）
  - ブラウザで動作（`localhost:5000` でアクセス）
  - 外部依存を最小化

### 2.2 ファイル構成（想定）

```
bibmanager/
├── app.py                  # Flaskメインアプリ
├── bib_parser.py           # bibファイルのパース・エクスポート
├── database.py             # SQLite操作
├── bibmanager.db           # データベース（自動生成）
├── templates/
│   └── index.html          # メインUI
├── static/
│   ├── style.css
│   └── app.js
└── README.md
```

### 2.3 起動方法（想定）

```bash
cd bibmanager
python app.py
# → ブラウザで http://localhost:5000 を開く
```

| `url` | TEXT | URL |

| カラム | 型 | 説明 |
|---|---|---|

| カラム | 型 | 説明 |
|---|---|---|
| `entry_id` | INTEGER | FK → entries.id |

#### `keywords` テーブル（多対多）

| カラム | 型 | 説明 |
|---|---|---|
| `id` | INTEGER PRIMARY KEY | - |
| `entry_id` | INTEGER | FK → entries.id |
| `keyword` | TEXT | キーワード（フリーワード） |

#### `reading_notes` テーブル（自分の読書メモ）

| カラム | 型 | 説明 |
|---|---|---|
| `id` | INTEGER PRIMARY KEY | - |

| カラム | 型 | 説明 |

## 4. 機能仕様

### 4.1 bibファイルのインポート

- UIからbibファイルをアップロード（またはパスを指定）して読み込む
- `cite_key` を主キーとして照合し、**差分インポート**を行う
  - 新規エントリ → 追加
  - 既存エントリ（cite_keyが一致）→ bibフィールドのみ上書き（メモ・タグは保持）
  - bibから消えたエントリ → 警告表示のみ（自動削除はしない）
- インポート結果（追加数・更新数・スキップ数）をサマリー表示する

### 4.2 bibファイルへのエクスポート

- 全エントリを元の形式でbibファイルとして出力
- エクスポートオプション：
  - タグ・キーワードをbibのカスタムフィールドとして埋め込む（`tags = {...}` 等）かどうかを選択可能
- ファイル名はデフォルト `exported.bib`

### 4.3 文献一覧表示

- 一覧はデフォルト **年降順** でソート
- 1行に表示する情報：cite_key, 著者（省略）, タイトル, 年, タグ（バッジ）
- 1ページあたりの表示件数は設定可能（デフォルト50件）
- クリックで詳細パネル（または詳細ページ）を開く

### 4.4 検索

以下のフィールドを対象に検索する。

| 検索対象 | 方式 |
|---|---|
| タイトル | 部分一致（大文字小文字無視） |
| 著者名 | 部分一致 |
| cite_key | 部分一致 |
| タグ | 完全一致（複数AND/OR選択） |
| キーワード | 部分一致 |
| 年 | 範囲指定（from〜to） |
| ジャーナル名 | 部分一致 |
| arXiv番号 | 部分一致 |
| 読書メモ・言及メモ | 全文検索 |

- 複数条件はAND結合
- 検索結果はリアルタイムに絞り込み（Enterキーまたは入力後即時）

### 4.5 文献詳細画面

各文献の詳細画面で以下を表示・編集できる。

**表示（自動取得）:**
- タイトル、著者、年月、ジャーナル、DOI、URL、arXiv番号、アブストラクト

**編集可能:**
- タグ（追加・削除、既存タグのオートコンプリート）
- キーワード（追加・削除）
- 読書メモ（Markdown記述、プレビュー表示）
- 他文献での言及（ソース情報＋内容を複数登録・編集・削除）
- bibTeX情報（raw_bibtexをコードブロックで表示、コピーボタン付き）

### 4.6 タグ管理

- タグ一覧画面（タグ名・使用文献数を一覧表示）
- タグのリネーム・削除
- 文献一覧をタグでフィルタリング

### 4.7 統計・概観

- 総文献数
- 年別件数グラフ（簡易）
- タグ別件数

## 6. APIエンドポイント設計（Flask）

| メソッド | パス | 説明 |
|---|---|---|

## 8. 技術的注意事項

### bibパーサーについて

- Pythonの `bibtexparser` ライブラリを使用（`pip install bibtexparser`）
- 著者フィールドは `and` 区切りで複数著者を分割して保存
- 特殊文字（LaTeXコマンド `\"{o}` 等）は、検索用に正規化した別フィールドを持つことを推奨

### arXiv情報の扱い

- `eprint` フィールドが存在する場合、arXivリンクを自動生成
- `archivePrefix = {arXiv}` をチェック

### データの安全性

- bibインポート時、既存のメモ・タグは絶対に上書きしない
- エクスポート前にdbのバックアップを自動作成（`.db.bak`）

## 10. 開発開始に必要なもの

Claudeに実装を依頼する際は、以下の順で進めると効率的です。

1. `bib_parser.py` — bibファイルのパースとSQLiteへの格納
2. `database.py` — DB初期化・CRUD操作
3. `app.py` — FlaskアプリとAPIエンドポイント
4. `templates/index.html` + `static/` — フロントエンドUI
5. 各フェーズの機能追加

実際のbibファイル（`bibbib.bib`）をテストデータとして使用することで、パーサーの動作検証が容易に行えます。
